#  YouTube - Interface

Uma reprodução da interface da página inicial do YouTube desenvolvida para praticar **HTML, CSS e JavaScript**.

##  Sobre o projeto

O projeto simula a interface principal do YouTube, incluindo cabeçalho, barra de pesquisa, menu lateral, categorias e cards de vídeos.

O objetivo foi praticar a criação de interfaces web utilizando **HTML, CSS e JavaScript**, com foco em organização, responsividade e interação.

##  Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Material Symbols
* Google Fonts

##  Funcionalidades

*  Layout responsivo
*  Abrir e fechar a barra lateral
*  Barra de pesquisa
*  Botão de pesquisa por voz
*  Categorias de vídeos
*  Cards de vídeos
*  Área de perfil
*  Adaptação para dispositivos menores
